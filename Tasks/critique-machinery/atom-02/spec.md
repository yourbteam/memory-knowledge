# Atom 2 — lens matrix

## Outcome

Opening a run crosses every immutable unit with seven fixed lenses: buyer-read, CFO, journalist,
employee/insider, competitor counter-position, benchmark-vs-reference, and upstream-trace. `status`
exposes partial coverage as partial. No cell, report, or document route returns critique results
until every cell is judged; each refusal states the count, cell identities, and repair action.

## Frozen real cases

- BTM Step 12 roadmap archive `b8d29d78cdfc446ed5d165ccb6bfba89bb2b0e12696bc3ee81ab1b8c9cab6db8`.
- Vivacom Step 10 scorecard archive `faf056757b70468c5b6723f46831d898ae78134916c5d4701c0260b27d39c6e3`.

Both are the exact Atom 1 case archives. The experiment opens their real page and stored payload,
marks only the first matrix cell as judged, and tries every route from that controlled partial state.

## Competing approaches

1. `terminal-only-gates`: completeness checks live only on report and document assembly; a judged
   single cell remains readable while the rest of the page is untouched.
2. `universal-gate`: one completeness boundary protects cell, report, and document routes; status
   can reveal counts and identities but never a completed-looking cell result.

## Criteria fixed before execution

Rank in this order across both pages: authentic open remains correct; matrix dimensions equal
units × seven lenses; status says partial; all three result-bearing routes refuse; refusal text
contains the missing count, concrete cell ids, and the action that satisfies it.

## Stopping condition

The assembled winner passes both pages, its exact source is promoted, repository tests pass, and
the actual CLI shows the expected matrix dimensions and actionable refusal on a partial real run.
