# Commit controller input-limit observation

Observed twice on 2026-09-05 before staging or any Git mutation. The registered
`commit_push_main_launch.py` controller displayed 21,183 changed paths. An explicit selection of
658 indices and then a reduced selection of 232 indices each stalled at the single-line
comma-separated picker before the verification prompt. The same exact reviewed scope can be
published without bypassing any boundary by dividing it across smaller controller-owned commits.

Stable boundary for later correction: the controller's exact-scope picker should accept a bounded
range syntax or repeated chunks so a large dirty worktree does not force either `0` (all paths) or
an oversized single terminal line.
