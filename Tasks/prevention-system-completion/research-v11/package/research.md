## Complete greenfield progressive UnitBudget algorithm

The approved target has no fixed whole-workflow duration and no invented aggregate value. Every durable task is classified into exactly one productive or mandatory role/overhead dimension. Every atomic task carries a total of 3,600,000 ms including retry. Before launch, the owner materializes the next task or parallel frontier from durable program state and fully reserves every task vector in that next task/frontier. The workflow aggregate is the component-wise sum of all materialized task vectors. A missing required role, an untyped task, an unresolved next frontier, or insufficient reservation rejects admission or persists a checkpoint before effects; continuation occurs only after a fully typed frontier can be fully reserved. This preserves progressive discovery while making every launched unit complete and pre-admitted.
