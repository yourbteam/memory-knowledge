The GET action constructs RetryCustomerSquareTransactionQuery(orderId) and returns its handler call. Atlas links the action to matching handler-injection and scoped-registration syntax and a candidate Handle method, while leaving receiver and cross-file type binding unresolved. In that candidate Handle body, it awaits CustomerCheckoutSupport.LoadOwnedOrderAsync(dbContext, currentUser, query.OrderUuid, cancellationToken) and assigns the result to order before checking Square configuration. If either Square AppId or CallbackUrl is blank, it returns CustomerSquareRetryResponse(0, null, null, "Square is not configured in the new API.").

When configured, it computes cents from order.Total × 100, rounds midpoint values AwayFromZero, casts to int, and formats invariantly. The payment data uses that amount, USD, CallbackUrl + "/customer/callback", AppId as client_id, notes "OrderID:" plus the order UUID, and CREDIT_CARD; the full data string is URI-escaped in the square-commerce-v1://payment/create deep link. The configured branch returns CustomerSquareRetryResponse(1, deepLink, CustomerCheckoutSupport.ResolveHomepageLink(order.TourTimeSlot!.Tour!, _options)) with three arguments.
