Before the order lookup, the handler requires authentication and a non-null current user ID, then loads the order. With `command.LinkUser=false`, the link branch does not assign `order.UserId` or `order.Updated`, so those fields remain unchanged. The handler then loads the current user and resolves the payment event type. If that type ID is present and no matching event-sync entry exists, it adds an entry with the user ID, email, event type, order UUID, and order total formatted as `0.00`, with UTC creation and update timestamps. It then awaits `SaveChangesAsync` whether or not it added an event-sync row.
