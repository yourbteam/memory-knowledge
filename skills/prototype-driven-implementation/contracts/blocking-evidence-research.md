# PDI Blocking-Evidence Research Contract

This is internal Prototype-Driven Implementation rigor, not a selectable skill or lifecycle
controller.

For one blocking evidence question exposed by the current prototype:

1. Inspect only the declared real repository, runtime artifact, contract, or primary-source boundary.
2. Separate confirmed evidence from unresolved uncertainty and cite the exact deciding evidence.
3. Do not build a general research package or introduce planning and implementation decisions.
4. Return the evidence, conclusion, uncertainty, and smallest evidence-backed delta to PDI.
5. PDI alone selects another prototype, promotion, or completion.

For a negative coverage or satisfaction conclusion, the evidence must cover both sides: the
evidence that defines the required behavior and the evidence that demonstrates the missing
coverage or behavior. A citation to only one side is insufficient and must return to evidence
collection before the conclusion can be handed to planning.
