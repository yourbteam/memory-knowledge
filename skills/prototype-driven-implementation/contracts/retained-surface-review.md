# PDI Retained-Surface Validation Contract

This is internal Prototype-Driven Implementation rigor, not a selectable skill or lifecycle
controller.

For one retained delta or the final accumulated implementation surface:

1. Compare the supplied surface with the approved outcome, observed gap, and governing evidence.
2. Identify actionable correctness, security, regression, and requirement-coverage findings.
3. Separate blocking defects from optional improvements and cite exact evidence.
4. Return findings to PDI. PDI alone selects another prototype, promotion, or completion.
5. Completion still requires confirmation through the real operator path after the retained surface
   has no blocking findings.
