# Internal Write-Code Support Contract

This contract supplies one bounded coding capability to Prototype-Driven Implementation. It is not
a selectable skill and never owns the implementation lifecycle.

- Change only the controller-approved delta and preserve unrelated user work.
- Inspect the real producer, boundary, and consumer before editing; fix the stable contract instead
  of accumulating exceptions.
- Run the narrow proof chosen for the current prototype and report the actual evidence.
- Return control after the delta and its focused verification; do not continue to another step.
