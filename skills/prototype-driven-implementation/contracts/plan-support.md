# Internal Plan Support Contract

This contract makes one observed implementation delta decision-complete for Prototype-Driven
Implementation. It is not a selectable skill and never owns the implementation lifecycle.

For the supplied approved outcome, envelope, current prototype, observed gap, and concrete
evidence:

1. Plan only the observed gap, never the full implementation lifecycle.
2. Ground every file, symbol, contract, behavioral boundary, and verification point in supplied
   or directly inspected evidence.
3. State the exact change, its stable producer-to-consumer boundary, and the proof that decides
   whether this delta serves the approved outcome.
4. Return unresolved decisions to PDI instead of spawning more planning or inventing milestones.
5. PDI alone selects another prototype, promotion, or completion.
