# Evidence admission contract v1

This prerequisite publishes shape only. It performs no admission, probe, model call or readiness decision.

Manifest kinds are evidence, telemetry and blockers. Every named source is an explicit path, digest and size; runtime admission must snapshot its bytes before registering a record. Evidence has six independently derived fitness booleans; producer claims are not verification. Immutable evidence and age-bounded evidence have different freshness rules. Access, reproduction and sharing receipts retain source identities and pointers. Missing or unfit evidence requires a finite recovery item. Local evaluation never grants model-sharing authority.

Legacy aliases are not ordinals in the current handoff. Each binding carries the old document identity, exact old text, explicit current requirement ID and exact current text. An unchanged statement uses byte equality; a changed statement requires the separately retained two-blind mapping proof. The captured returning-discount mapping is r1→2, r2→1, r3→5, r4→3, r5→4, r6→7, r7→6, where the right side is display ordinal only; production records keep exporter-assigned IDs. This mapping is fixture evidence, not a product hardcoded alias table.

## Atom 6 admission

The opt-in controller imports evidence, telemetry and blocker manifests at `start`, snapshots every named source under the same input-count/byte limits, and records the graph before/after hashes in its immutable start event. No external probe or model is launched. The local file-capture receipt proves file capture only, not the truth of an arbitrary domain claim. Evidence-sufficiency judgment remains a later interview capability.

The existing canonical Work Memory validator validates blocker lifecycle history. Its six local runtime modules are captured, hash-checked and replay-bound; input files are never executed. Each open occurrence remains blocking. A separate manifest referencing identical ledger bytes does not duplicate an already registered source-bound condition. Adding another ledger also admits its other open occurrences rather than silently treating them as irrelevant.

All six fitness dimensions are derived at the recorded admission time. Replay preserves that as-of assessment. `model-authorized` alone never grants sharing: until owner-authority admission is implemented, that declared use remains unfit, even if a receipt file exists. This atom adds neither owner-decision acceptance nor post-start evidence-response transitions.
